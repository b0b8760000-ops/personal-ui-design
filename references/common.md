# 共用設計與互動方法

## 將模糊意見轉成可判斷的問題

| 使用者描述 | 先看什麼 | 可能的改善方向 |
|---|---|---|
| 重點不明、卡片太多 | 主要任務、資訊優先順序、閱讀路徑 | 建立主次，依概覽／趨勢／明細、狀態或時間組織 |
| 太複雜 | 必要內容、重複資訊、主要操作 | 收斂內容與控制，保留任務所需資訊 |
| 太平淡 | 品牌、內容特性與使用情境 | 加強有目的的對比與辨識度，避免純裝飾 |
| 字體不對、跨頁不一致 | 字級、字重、行長、間距、元件及變數引用 | 修正層級及共享規範 |
| 操作生硬 | 觸發方式、回饋延遲、動態與資料狀態 | 明確狀態並加入適當回饋 |
| 按鈕沒反應、資料不更新 | 事件、請求、狀態更新、服務回應及 Log | 先找功能原因，視覺打磨不能代替修復 |

這些是判斷提示，不代表原因已確認。特定字體、配色、圓角或動畫多寡，不能單獨判定好壞或是否由 AI 生成。

## 規範與交接

依需要明確記錄：字體層級、配色用途、間距、圖片比例、元件變體，以及載入、空資料、停用、錯誤、成功狀態。沿用有效規範，標示新增內容；示範數值不當成所有專案的標準。

交付可編輯設計檔時，保留文字、圖層、元件、變數與素材。已有程式且只需小改時，直接沿用現有規範，不強制新增設計工具。

需要設計到程式的交接時，提供目標畫板／圖層、素材、元件／變數對應、技術棧、互動與響應式要求、驗收條件。檢查私密資料、素材使用權與檔案權限。生成碼要比對既有元件與資料流，避免重複元件、硬編碼或覆寫正常功能。

MCP 是連接外部能力的協定；可執行動作取決於當下服務、工具清單與權限。參考圖生成、設計編輯、程式生成與成功執行分別確認。工具不可用時說明缺口，提供在現有環境可完成的方案；不假稱已呼叫工具、不自動安裝或訂購服務。

本版只使用零新增付款的設計資源；免費預覽不代表素材可免費下載、修改或商用。外部能力需要付費或條件不明時，改用程式原型與自有素材。AI 助手協助寫程式不代表其帳號或模型服務免費，也不因此啟用新增計費端點。

## 互動需求的寫法

按需要描述「使用者操作 → 目標元素及相關元素如何回應 → 最後資料狀態 → 連續操作、取消、失敗及減少動態的處理」。

### 十種參考模式

來源是第三支手機 App／小程式情境影片；以下行為原則可跨平台參考，API 與測試方法各平台處理。按需選用，不要求全部加入。

| 模式 | 視覺描述 | 必須保持的功能關係 |
|---|---|---|
| 主題切換 | 從點擊處圓形揭露新主題 | 不整體縮放或扭曲內容；快速重切仍以最新主題為準 |
| 拖曳排序 | 拖起一列，其他列連續讓位 | 最終順序真正更新；取消／失敗可恢復，另提供點按的移動選單或上移／下移等方式 |
| 批次勾選 | 各項勾選依序回饋 | 實際選取與計數一致；取消後舊動畫不覆蓋新狀態 |
| 滑桿吸附 | 慣性移動後停在刻度 | 最終值、範圍與提交時機清楚；精準任務保留直接輸入或加減控制 |
| 文字展開 | 容器隨內容展開，箭頭轉向 | 不裁切文字，展開狀態與焦點一致 |
| 步驟進度 | 進度線略超過後回彈 | 真實完成步驟與輔助技術讀值保持正確 |
| 開關聯動 | 同組其他開關有輕微視覺回饋 | 其他開關的開／關值不變；易誤解時省略聯動 |
| 刪除卡片 | 曲線移向刪除圖示，縮小及淡出 | 根據資料結果確認刪除，失敗恢復，視任務提供撤銷或確認 |
| 卡片堆疊 | 捲動時卡片縮小退後 | 遮擋不妨礙閱讀或造成隱藏操作誤點 |
| 標籤選取 | 選中項放大，鄰項讓位 | 選取、篩選與焦點同步，長字及窄畫面不重疊 |

### 動畫與資料狀態

資料操作成功由實際操作／服務回應確認。若採樂觀更新，明確區分暫時畫面與已保存狀態，定義失敗回復及連續操作的先後處理。不能用動畫結束當作儲存成功。

拖曳不應成為唯一操作方式。網頁除鍵盤支援外，還需評估不依賴拖曳的單一指標方式，例如點按「移到…」或上移／下移；只有鍵盤替代不能自動滿足 WCAG 2.5.7 的要求。例外需依實際任務判斷。[W3C Dragging Movements](https://www.w3.org/WAI/WCAG22/Understanding/dragging-movements.html)

為非必要動態提供簡化回饋，保留清楚狀態。WCAG 2.3.3 為 AAA，不能描述成所有產品均必須達成的標準。[W3C Animation from Interactions](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)

## 按工作選驗收

- 視覺：核心資訊、閱讀、對比、對齊、跨頁規範與長內容。
- 互動：實際狀態、快速重複、取消、錯誤、恢復與非拖曳操作。
- 資料：載入／空資料／錯誤／過期、保存與同步；不將模擬資料表述為真實串接。
- 平台：依網頁或手機參考安排操作與驗證。沒有相應環境時保留未驗證項目。
- 修改：針對受影響的原功能做有意義的回歸；低影響文案或樣式不為檢查而新增大量測試。

具體版本、API 或能力要在使用時核對官方文件；以上來源為建立第一版時查核過的參考，不能代替未來環境確認。
